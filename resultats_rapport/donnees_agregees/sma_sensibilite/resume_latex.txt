Sur 19 exécutions de scénarios (15 scénarios, 3 graines pour les scénarios aléatoires), les coefficients qui modifient les décisions du système sont : retard / min (x p), avance / min (x p), report / jour (x p), déprogrammation (x p), reprise autre chirurgien, attente urgente / min, attente différable / min. Les coefficients suivants n'ont pas d'effet significatif : stabilité (réopt. globale), rétention SSPI / min, chirurgien d'astreinte, lit de réserve, lit hors capacité, attente vitale / min. Seuil de significativité : variation entre deux exécutions identiques de la référence (0.00 \% d'affectations, 0 urgence(s), 0 patient(s) perturbé(s)).
